# 实践: 文档驱动的多角色协作

> 提炼自 VoiceOS 3.0 协作体系

## 问题

多个 AI Agent 角色协作时，如果靠对话沟通，信息会丢失、版本会混乱、无法追溯。

## 方案

角色之间**不对话**，只通过文件沟通：

```
指挥者 → 执行者: docs/specs/batch-N.md（Spec 文件）
执行者 → 审核者: git commit + progress.md 状态更新
审核者 → 指挥者: docs/reviews/batch-N.md（审核报告）
优化者 → 指挥者: docs/optimizations/YYYY-MM-DD-{主题}.md（优化方案）
```

每个角色读取上一个角色的产出文件，写入自己的产出文件。没有人需要"在场"等待。

## 为什么有效

- 文件不会丢失（对话上下文会压缩）
- 文件有版本控制（可以 git diff）
- 异步协作（写完文件就可以走，下一个角色自己来读）
- 可追溯（每个决策都有文档记录）

## 适用条件

- 多角色（2 个以上）AI 协作
- 需要异步工作（不同时在线）
- 需要追溯决策过程
